Программа "Ведения списка дел"

Список задач:
- Отображение списка задач на главном экране.
- Задача должна содержать название, описание, дату создания и статус
(выполнена/не выполнена).
- Возможность добавления новой задачи.
- Возможность редактирования существующей задачи. -
Возможность удаления задачи.
- Возможность поиска по задачам.

Загрузка списка задач из dummyjson api: https://dummyjson.com/todos.
При первом запуске приложение загрузит список задач из
указанного json api.

Многопоточность:
- Обработка создания, загрузки, редактирования, удаления и поиска задач выполняться в фоновом потоке с использованием GCD. -
Интерфейс не должен блокироваться при выполнении операций.

CoreData:
- Данные о задачах сохраняються в CoreData.
- Приложение корректно восстанавливает данные при повторном
запуске.

Также реализованы подходы: 
- DI (к API)
- частично архитектура VIPER (для галочки)
